# The sign

This is Dan Shulman's software shop. It builds small pieces of software, with Claude and other AI assistants doing the building, for three kinds of people: Dan himself, his family and friends, and his firm, Shulman Advisory. Building for those three is the point. Commercial ideas exist, but they are not what the shop is for right now.

What gets built is one of three things: tools for doing (studying a language, flying the simulator, keeping the apartment running); tools for running the shop (the wall that tracks every thread of work, Chief, the starting kit); and tools for building tools.

The shop runs like a small software company, in how it works rather than in what it sells. Every app starts from the same kit and carries its own page saying what it is, its own checks, and its own rules for what a coding agent may touch. GitHub holds the one true copy of everything; Fly.io rents the computers it runs on. Where the shop is heading: a coding agent can run a long build on its own, and Dan trusts what comes back.

Rules the shop keeps:

- Nothing nags. No reminders, streaks, or check-ins; a tool speaks when asked. A system that needs watching has failed.
- Replace, don't add. A new tool or routine replaces effort that already exists; it never creates a new obligation.
- Absence is unknown, never zero. If the files don't say, say "unknown."
- Plain language. Dan is not a coder; anything he reads explains itself.
- Dan sets the order of work. Tools and assistants remind him of dependencies and otherwise follow.

Who builds: Dan builds; Jimmy and Oren build; Dan starts and hands off; Dan builds and a teammate gives feedback; teammates learn to build their own. Which route an app is on is written on its page.
